# Noor Younes — Portfolio

Personal portfolio website (React + TanStack Start + Tailwind CSS).

## Run locally

```bash
npm install
npm run dev
```
Open http://localhost:8080

## Deploy to Vercel

1. Push this folder to a new GitHub repository.
2. Go to vercel.com → **Add New… → Project** → import that repository.
3. Leave the defaults:
   - Build command: `npm run build`
   - Install command: `npm install`
   - Output: detected automatically (`.vercel/output`)
4. Click **Deploy**.

That's it — the build already targets Vercel, so no extra settings or
environment variables are needed. You'll get a URL like
`noor-younes-portfolio.vercel.app`, and you can attach your own domain
from the project's **Settings → Domains** page.
